# Prompt Engine Design

Prompt Engine stores reusable AI instruction templates.

Components:

## Material Rule
Defines how AI reads source material.

## Assessment Rule
Controls assessment style.

Example:
- Formative
- Summative
- Diagnostic

## Difficulty Rule

Controls:
- Easy
- Medium
- Hard
- HOTS

## Question Rule

Controls:
- Multiple Choice
- Essay
- True False

## Output Rule

AI output must contain:

Question
Options
Correct Answer
Explanation
