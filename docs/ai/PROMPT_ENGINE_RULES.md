# Prompt Engine Rules

Prompt Engine adalah kumpulan aturan prompt yang dikelola developer.

## Components

## Material Rule
Mengatur cara AI membaca materi.

## Assessment Rule
Mengatur tipe assessment.

Contoh:
- Formative
- Summative
- Diagnostic

## Difficulty Rule
Mengatur tingkat kesulitan:
- Easy
- Medium
- Hard
- HOTS

## Question Rule
Mengatur format soal:
- Multiple Choice
- Essay
- True False

## Output Rule

Output AI wajib:
- Question
- Options
- Answer
- Explanation
